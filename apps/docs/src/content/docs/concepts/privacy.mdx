Trails is designed around metadata over transcripts. Each stage derives the smallest bounded representation needed by the next stage.

## Stays on the source Mac

- Raw coding-agent transcript bodies.
- Local transcript file paths.
- The original session files owned by Claude Code, Codex, omp, or pi.
- Parsing of those files.

## Reaches your hub

A collector sends normalized observations over your tailnet:

- source type;
- a session identifier used for idempotent ingestion;
- working directory and branch context;
- timestamps and event counts;
- the first prompt;
- minute-level activity;
- a bounded digest used for optional summarization.

The hub stores these observations in its local SQLite database.

## Reaches the browser

The private web app receives the information needed to render the timeline and save your organization. It does not receive source-local session identifiers or bounded digests.

## May reach the inference relay

When optional generated summaries are enabled, the hub sends bounded summary input through an authenticated Cloudflare Worker. It does not send complete transcripts.

Current limits are:

- up to 9,000 characters for a session summary input;
- up to 12,000 characters for a day summary input.

If the relay is unavailable, timeline collection continues. Trails uses the session's first prompt as fallback copy.

## Network boundary

The hub server listens on loopback rather than the local network. Tailscale Serve is the access boundary for the private web app and collector endpoint. Devices must be on the same tailnet to reach it.

<Aside type="note" title="You hold the system">
  Your hub, database, backups, tailnet, and optional inference token remain under your control. Trails does not need a public application server.
</Aside>
