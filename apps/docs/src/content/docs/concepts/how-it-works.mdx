Trails is a local-first hub-and-collector system. One Mac owns the canonical state. Every participating Mac contributes normalized observations from its own coding-agent sessions.

## The path from session to day

<Steps>
  <Step title="A coding agent leaves a session log">
    Claude Code, Codex, omp, and pi already record local session history as part of their normal operation.
  </Step>
  <Step title="The local collector reads changed sessions">
    Once a minute, the collector parses only files that may have changed. Transcript parsing happens on the Mac where the session was created.
  </Step>
  <Step title="The collector normalizes the observation">
    Trails derives timestamps, project context, event counts, the first prompt, minute activity, and a bounded digest. Raw transcript paths and bodies do not cross the source-machine boundary.
  </Step>
  <Step title="The hub commits canonical state">
    The always-on Mac stores observations and user edits in SQLite. Repeated submissions are idempotent, so retries do not duplicate sessions.
  </Step>
  <Step title="The browser reads the private timeline">
    The web app is served through Tailscale. It shows day, week, thread, and project views without exposing source-local session identifiers or digests.
  </Step>
</Steps>

## Attention and agent time

Agent-heavy work has two different clocks:

- **Agent time** is when a coding agent was active, including periods when it continued without you.
- **Attention time** is when your prompts and steering show you were present.

Trails renders both in one lane instead of collapsing them into wall-clock duration. The distinction is how it reconstructs the shape of your day without asking you to run a timer.

## The hub owns the truth

The hub Mac owns:

- the SQLite database;
- project names and assignments;
- thread and divergence-pocket state;
- generated summaries;
- the private web service;
- daily backups.

Browsers are readers and editors over that canonical state. A page reload on another device converges on the same organization.

## Cloudflare's narrow role

Cloudflare does not host the trails database or web app. When summary generation is enabled, a small authenticated Worker can relay bounded inputs to Workers AI. Complete transcripts are not sent through that relay.
