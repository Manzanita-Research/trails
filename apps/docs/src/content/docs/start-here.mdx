Trails reconstructs your days from the coding-agent sessions already on your Macs. It turns those sessions into a private timeline of projects, working days, and active threads.

It is a memory system, not a time tracker. There is nothing to start or stop while you work.

## What you need

- macOS on every participating computer.
- [Tailscale](https://tailscale.com/download/mac) installed and connected to the same tailnet on every Mac.
- One Mac that can remain awake, logged in, and connected. This is your **hub**.
- An invitation to the current alpha.

Existing sessions from Claude Code, Codex, omp, or pi will make trails useful immediately. New sessions appear after installation too.

You do not need Bun, Node, a repository checkout, or a public server.

<Aside type="caution" title="Private alpha">
  Trails is changing quickly. Installation details and stored data may change between alpha releases. Rerunning the installer is the supported update path.
</Aside>

## The short version

One always-on Mac owns the trails database and private web app. A small collector on each Mac reads changed agent sessions and sends normalized observations to that hub. Tailscale keeps the hub off the public internet.
